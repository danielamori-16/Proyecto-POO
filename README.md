# 🎮Escape del Laboratorio

## 📖 Descripción
Un científico intenta escapar de un laboratorio lleno de robots y trampas experimentales

El jugador controlará al Cinetífico

Un científico despierta atrapado en un laboratorio depsues de que un experimento salió mal.
Para lograr salir del laboratorio con éxito, deberá de conseguir puntos a traves de los desafíos.
